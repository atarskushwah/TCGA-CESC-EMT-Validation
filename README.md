# TCGA-CESC-EMT-Validation
Reproducible TCGA-CESC external validation workflow for EMT-related biomarkers (CD44, CTNNB1, MMP7, MMP9, VCL, TIMP1, and TIMP2) in cervical cancer, including expression profiling, correlation network analysis, EMT-score generation, Kaplan–Meier survival analysis, and Cox regression modeling.
